# Élan Fitness

Site web multipage réalisé pour **Élan Fitness** une salle de sport.

## Description du projet

Le projet consiste à transformer un ancien site one pager en un site multipage afin d'améliorer la présentation des contenus, de faciliter la navigation et de renforcer la présence de la salle sur le web.

Les pages réalisées sont :

1. **Accueil** : présentation de la salle et découverte des programmes.

2. **Programmes** : présentation des cours et des formules proposées.

3. **À propos** : présentation de l'histoire des valeurs et de l'équipe.

4. **Contactez-nous** : formulaire de contact coordonnées et plan d'accès.

Ces différentes pages correspondent aux fonctionnalités demandées dans le brief.
